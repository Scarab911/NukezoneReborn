# NukezoneReborn

A modern remake of the classic browser-based nuclear war strategy game [Nukezone.nu](https://nukezone.nu).

Build your nation. Arm your arsenal. Launch or be launched.

---

## Tech Stack

- **Next.js 15** — App Router, Server Components, API Routes
- **TypeScript** — Strict mode throughout
- **Tailwind CSS v4** + **shadcn/ui** — UI components
- **Zustand** — Client state management
- **TanStack Query** — Server state and caching
- **Framer Motion** — Animations
- **Socket.io** — Real-time WebSocket communication
- **PostgreSQL** + **Prisma** — Database
- **NextAuth.js v5** — Authentication
- **PWA** — Mobile installable, offline capable

## Getting Started

See [ENVIRONMENT_SETUP.md](ENVIRONMENT_SETUP.md) for full setup instructions.

```bash
npm install
npm run dev
```
